# Weather Forecasting

A simple and interactive web application for real-time and 5-day weather forecasting, built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to check the current weather and a 5-day forecast for any city worldwide. By entering a city name, users receive up-to-date weather information—including temperature, humidity, wind speed, and general conditions—directly fetched from a weather API. The app features a modern, responsive design for a seamless experience across devices.

## Features

- Search weather by city name
- Display current weather: temperature, humidity, wind speed, and conditions
- 5-day weather forecast for the selected city
- Responsive and intuitive user interface
- Clean and readable codebase

## Technologies Used

- **HTML** (55.1%)
- **CSS** (26.7%)
- **JavaScript** (18.2%)

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/srinivas-sadanala/weather-forecasting.git
   cd weather-forecasting
   ```

2. **Open the application:**
   - Open `index.html` in your web browser.

3. **API Setup:**
   - The app fetches weather data from a weather API (such as OpenWeatherMap).
   - Add your API key in the relevant JavaScript file as instructed in the code.

## Usage

1. Enter the name of a city in the search box.
2. Click the "Search" button.
3. View the current weather and 5-day forecast below.
